# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in QAVeil AI, please do not publish sensitive details in a public GitHub Issue.

Use a private channel made available by the maintainer, **Marco Aurélio Gomes**, and include reproduction steps, affected version or commit, impact, and any proposed mitigation when possible.

## Scope

This policy covers the QAVeil AI source code, its documented local-development configuration, and its public repository assets.

QAVeil AI is currently under active development. Reports are reviewed on a best-effort basis; no response-time SLA is guaranteed.
